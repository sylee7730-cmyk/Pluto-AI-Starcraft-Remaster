# 공개 커스텀 1대1 대전 개발 기록

2026-09-30. 목표는 리마스터 공개 커스텀 방에서 일반 게임 클라이언트를 사용하는 사람과 Pluto가 대결하는 것입니다.

## 구현

- 명시적 `-Multiplayer` 실행 옵션과 별도 런타임 폴더.
- 로컬 플레이어가 실제 참가자인 1대1 Melee 경기 인식. 상대 사람이 있는 경기도 허용.
- 리플레이, 관전자 로컬 슬롯, 비-Melee, 다인전 차단.
- 멀티플레이에서 로컬 게임 속도 테이블 변경 금지.
- 멀티플레이 기권 시 로컬 승패 메모리를 직접 바꾸지 않고 게임 루프 종료 경로 사용.
- BWAPI의 멀티플레이 표시와 턴 레이트 기반 지연 추정값 제공.
- 원본 추론기의 straddle 모드와 기본 10ms 프레임 대기 예산 적용.
- 별도 `-Challenge` 실행기로 Top vs Bottom·FFA·밀리의 1대다 실험 모드 추가. 기존 실행기의 허용 조건과 구분하며 [별도 검증 기록](CHALLENGE.md)을 참고합니다.

## 현재 확인

- Win32 Release 빌드 통과.
- `command-translation`, `session-admission`, `korean-messages`: 3/3 통과.
- Windows PowerShell 5.1 실행기로 실제 StarCraft 1.23.10.13515 x86 프로세스 17368 시작, `MH_OK` 훅 초기화.
- 사용자가 Battle.net 로그인과 Windows 네트워크 허용을 완료한 후 Korea 서버에 접속했습니다.
- 사용자가 실행한 밀리 공개방 3경기에서 봇 초기화와 명령 전송, 경기 종료 로그를 확인했습니다. 리플레이 길이는 26,574 / 25,952 / 14,494프레임입니다. 사용자는 해당 공개방 시험에서 이상이 없었다고 보고했습니다.
- 이후 테스트 경기에서 봇이 시작하지 않은 원인은 유즈맵·FFA·Top vs Bottom 설정입니다. [상세 진단](SESSION-DIAGNOSIS-20260930.md)을 참고하세요.
- 차단 이유 표시와 주요 안내 한글화를 적용한 빌드와 자동 테스트 3개가 통과했습니다. 이 DLL의 실제 경기 내 한글 표시 확인은 아직 수행하지 않았습니다. [한글 안내 검증](KOREAN-MESSAGES.md).

## 남은 검증

- 실제 네트워크 명령 적용 지연 측정 및 상대 클라이언트 상태 대조.
- 모든 종료·기권·연결 끊김 상황의 처리.
- LAN 환경의 별도 재현.

기존 `RESULTS.md`의 오프라인 세 종족 승리는 멀티플레이 검증 결과가 아닙니다. 사용자 공개방 기록은 DLL `c730666a71c2c92be46cc944b93b18d6871efe0f4fd1637a383bb1fddc3f8b37`에서 생성됐습니다. 최신 진단 개선·한글화·Challenge 빌드의 해시는 `SHA256SUMS-multiplayer.txt`에 기록합니다. 기존 오프라인 배포 ZIP은 보존합니다.

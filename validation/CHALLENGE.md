# 콘텐츠용 1대다 실험 모드

2026-09-30. `-Challenge` 및 `Start Pluto Challenge.cmd`를 추가했습니다. 현재는 구현·독립 검증 완료, 실제 Top vs Bottom/다인전 경기 검증 전입니다.

## 범위

| 실행 방식 | 허용 조건 |
|---|---|
| 기존 오프라인 | 밀리, 나와 컴퓨터 1명 |
| 기존 멀티플레이 | 밀리, 실제 참가자 2명 |
| Challenge + Multiplayer | 밀리·FFA·Top vs Bottom, 참가자 2~8명, 플루토에게 동맹 없음 |
| Challenge 오프라인 | 사용자 지정 밀리 등의 허용 모드, 나 이외 참가자는 모두 컴퓨터 |

사람들이 같은 팀으로 플루토를 상대하려면 Top vs Bottom을 선택하고 플루토를 혼자 한 팀에 둡니다. 공유 소유권을 사용하는 Team Melee/Team FFA, UMS, 리플레이, 관전자, 플루토 편에 아군이 있는 팀전은 거부합니다. 플레이 도중 로컬 플레이어와 동맹이 생기면 대기 중인 봇 명령을 폐기하고 그 경기의 AI를 중단합니다.

## 원본 모델과 구현

[원본 README](https://github.com/tscmoo/pluto)는 1대1 밀리와 바이너리 배포를 명시합니다. 학습 코드와 모델 입력 사양은 공개 소스로 제공되지 않습니다. 이 실험판은 재학습하지 않고 기존 CoG 2026 모델을 그대로 사용합니다.

고정된 `pluto.dll` SHA-256은 `7e360b643c8c0156c03fe0cad9972a3058138ccfe22f921c5b4e0cd0aaf0abef`입니다. 이 바이너리의 RVA `0x33f70` 관측 함수는 활성 유닛 목록을 순회하며 소유자가 자기 슬롯이면 0, 다른 슬롯 0~7이면 1, 중립이면 2로 분류합니다. 다른 플레이어에 대한 분기 RVA `0x34488`은 가시성 검사로 이어집니다. 이 경로에는 동맹 구분이 없어 플루토에게 아군이 있는 경우는 지원하지 않습니다.

브리지는 게임의 실제 모드와 Top/Bottom 팀 정보를 BWAPI에 전달하고, 닫힌 슬롯을 적 목록에서 제외합니다. 실제 소유권이나 게임의 동맹·자원·명령 동기화를 변경하지 않습니다. 모든 적 유닛은 기존 가시성 규칙을 통과해 원본 관측 코드로 들어갑니다. 원본의 일부 상대 종족 및 오프닝 선택은 한 명 기준으로 남습니다.

## 검증 결과

- Win32 Release 빌드 통과.
- CTest 3/3 통과: 명령 변환, 경기 입장/동맹 조건, 한국어 메시지.
- 입장 테스트는 로컬 슬롯 0~7 각각에 대해 상대 1~7명, 세 게임 방식, 상대끼리의 동맹, 플루토와 단방향/양방향 동맹, 오프라인 컴퓨터들, 멀티플레이 비활성화, 리플레이 및 미지원 모드를 검사합니다.
- `pluto-observation-probe`는 원본 DLL의 해시와 메모리 바인딩을 먼저 검증한 후, 별도 프로세스에서 원본 관측 함수를 직접 호출했습니다. 자기 유닛 1개, 서로 다른 두 상대의 서로 다른 종족 유닛, 중립 유닛, 안개 속 적을 제공하여 슬롯 8가지 모두에서 소유 분류·유닛 핸들·두 상대 동시 포함·보이지 않는 적 제외를 확인했습니다.
- 위 프로브는 게임이나 추론 엔진을 실행하지 않으며 실제 게임 프로세스에 접근하지 않습니다. 따라서 실제 전투 판단이나 네트워크 안정성을 증명하는 테스트는 아닙니다.
- Windows PowerShell 실행기의 `-Multiplayer -Challenge -VerifyOnly`로 원본 파일과 브리지 존재 확인을 수행합니다. 실제 경기 시작은 아직 하지 않았습니다.

빌드 결과: [공개 빌드 요약](BUILD-SUMMARY.md). 프로브 결과: `challenge-observation-probe.txt`. 바이너리 해시: `SHA256SUMS-multiplayer.txt`.

프로브를 다시 빌드하려면 CMake의 `pluto-observation-probe` 타깃을 지정한 뒤 `pluto-observation-probe.exe <원본 pluto.dll 절대 경로>`로 실행합니다. 테스트 소스는 `tests/pluto_observation_probe.cpp`입니다. 원본 DLL은 패키지에 포함하지 않습니다.

## 실전에서 확인할 사항

우선 128×128 이하 크기의 일반 밀리용 맵에서 Top vs Bottom 1대2로 시작합니다. 시작 안내와 실제 명령 전송, 두 상대 병력과의 교전, 상대 한 명 탈락 후 진행, 경기 종료 및 다음 경기 재시작을 확인해야 합니다. 로그는 `runtime-challenge/`에 따로 남습니다.

상대 숫자 증가에 따른 추론 지연, 원본 1,700 유닛 호환 한계, 여러 기지에 대한 정찰·공격, 원본의 승률 추정 및 자동 기권은 실제 대전으로 확인해야 합니다. 총 8명의 입장을 허용하는 것은 1대7 전투력이나 완주를 보장하지 않습니다. 기존 밀리 공개방 3경기 검증 기록을 이 새 모드의 실전 검증으로 해석해서는 안 됩니다.

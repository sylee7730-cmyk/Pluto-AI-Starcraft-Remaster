# 게임 내 주요 안내 한글화

2026-09-30. 원본 Pluto 바이너리를 수정하지 않고 브리지의 로컬 표시 단계에서 번역합니다.

## 적용 문구

| 원문 종류 | 한글 표시 예 |
|---|---|
| Pluto online / gl hf | 플루토: 준비 완료. 즐거운 경기 되세요! / 모델 이름 |
| action latency | 플루토: 명령 적용 지연 6프레임 (학습 기준 4프레임). |
| inference too slow | 플루토: 추론 속도가 부족합니다 (계산당 약 109ms). |
| decisions late | 판단이 약 2.1프레임 늦어져 플레이 성능이 떨어질 수 있습니다. |
| stalling the game | 판단마다 게임이 약 258ms 대기하여 진행이 느려질 수 있습니다. |
| quitting in 10 seconds | 플루토: 10초 후 게임을 종료합니다. |
| 지원하지 않는 게임 방식 | 플루토 시작 불가: 현재 게임 방식은 유즈맵 (Use Map Settings)입니다. |
| 승률 그래프 F1500 win=0.731 | F1500 승률=0.731 |

추론 엔진 시작 실패의 요약과 `gg`도 번역합니다. 알려지지 않은 문구와 상세 오류 정보는 원문을 보존합니다. 추론기의 파일 로그와 실행 옵션 이름은 번역 대상이 아닙니다.

## 구현과 검증

- SCR의 기존 로컬 `print_text` 호출에 UTF-8 문자열을 전달합니다. 상대에게 네트워크 채팅을 보내지 않습니다.
- 관련 C++ 타깃에 `/utf-8`을 적용합니다. 그래프는 `MultiByteToWideChar(CP_UTF8)`와 `DrawTextW`, 한국어 지원 글꼴을 사용합니다.
- 원본 `bot_text` 로그와 모델 이름, 프레임 및 시간 수치, 색상 제어 문자를 보존합니다.
- 실제 로그의 추론 시간 86/89/90/109/122/127/141/300/812ms, 판단 지연 2.0/2.1/2.2프레임, 게임 대기 43/48/51/80/258ms, 명령 지연 3/5/6프레임을 검증했습니다.
- 원본에서 미리 줄을 나눈 경고와 완전한 한 문장 입력의 번역 결과가 같은지 검사했습니다. 알 수 없는 문구가 손실 없이 통과하는지, UTF-8이 유효한지 확인했습니다.
- UMS·FFA·Top vs Bottom 차단 문구에 밀리 2인 경기라는 해결 방법이 포함되는지 확인했습니다.
- Win32 Release 빌드 및 CTest 3/3 통과. 공개 저장소에는 [빌드 요약](BUILD-SUMMARY.md)을 포함합니다.

현재 실행 중인 게임에는 적용하지 않았습니다. 게임 종료 후 `Start Pluto Multiplayer.cmd` 또는 오프라인 실행기로 다시 시작해야 적용됩니다. 실제 게임 화면의 한글 렌더링은 아직 확인하지 않았습니다. 공개방에서 검증된 기존 DLL과 이번 DLL을 구분하려면 `MULTIPLAYER.md`와 `SHA256SUMS-multiplayer.txt`를 참고하세요.
